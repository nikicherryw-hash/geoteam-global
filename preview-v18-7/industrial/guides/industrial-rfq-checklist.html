How to Prepare an Industrial Equipment RFQ

A practical checklist for identifying exact industrial spare parts and collecting comparable offers.

All guides ↗

Start with the installed equipment

Record the nameplate, exact model and the manufacturer’s full order code including suffixes. For an obsolete part, attach the installed unit photo and original specification rather than assuming a current replacement is plug-and-play.

Define operating conditions

Specify media, temperature, pressure, voltage, duty cycle and environmental classification as relevant. A broad item name such as “pump” or “sensor” will not produce a technically comparable quotation.

Set the commercial request

Include quantities, requested condition, preferred Incoterms with named location, destination, packaging, required date and quotation currency. Separate mandatory requirements from optional preferences.

Ask for evidence, not promises

Request origin, manufacturer marking, documentation, factory/test records or calibration evidence where necessary. Supplier stock and lead time must be confirmed as of quotation date.

Evaluate offers consistently

Compare full order code and revision first, then delivery, document coverage, warranty, logistics and export eligibility. Preserve technical deviations as explicit questions rather than silently accepting an alternate.
