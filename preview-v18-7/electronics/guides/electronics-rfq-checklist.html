How to Prepare an Electronic Components RFQ

Build a quotation request that preserves ordering codes, quantity, packaging and technical evidence.

All guides ↗

Begin with the full ordering code

Use the manufacturer name and the complete manufacturer part number, including suffixes for package, temperature grade, tape-and-reel options and programmed variants. A base-series name is not enough for buying.

Include manufacturing and handling requirements

Specify quantity, acceptable date-code conditions, permitted split lots, labeling and packaging format. If the design has ESD or moisture-sensitive handling requirements, state them clearly.

Separate alternatives from the requested part

The original required part should remain visible as the primary line. Record alternate proposals separately, with datasheet deviations and engineering approval status.

Define traceability and documentation

Ask for the supplier name, manufacturer traceability evidence if required, original packaging photographs, test or inspection documents if applicable, and the condition declaration.

Make the commercial response comparable

Request price and currency, MOQ, order multiple, lead time, Incoterms with named place, payment terms and validity period. Compare like-for-like product conditions.

Preserve compliance review

Record destination and end-use accurately when requested by authorized compliance participants. Any export-controlled item or restricted transaction requires dedicated review before commitments.
